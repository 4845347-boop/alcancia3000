Alcancía 3000 · Guía de operación en laptop

INDEL · 3.º Desarrollo de Software B · 21 de octubre de 2026

1. Presentación

Alcancía 3000 es una aplicación web local de finanzas personales para registrar ingresos y gastos, calcular saldos, organizar metas de ahorro y motivar mediante retos, rachas y logros. El archivo entregado es alcancia3000.html, ejecutable en un navegador de laptop.

Los datos se almacenan mediante localStorage del navegador. No existe servidor, inicio de sesión, cuentas bancarias ni SQLite en este archivo. El funcionamiento offline se refiere a que el HTML y sus scripts están incluidos en el archivo; los datos se conservan en el perfil del navegador mientras su almacenamiento no sea borrado.

2. Requisitos para utilizarlo

Una laptop con navegador moderno (Chrome, Edge o Firefox) que permita JavaScript y almacenamiento local. No requiere Python, Visual Studio, Android ni conexión a una API.

Abrir la aplicación

  1. Guardar alcancia3000.html en una carpeta de la laptop.
  2. Hacer doble clic en el archivo o abrirlo desde el navegador.
  3. Esperar a que aparezca la vista Inicio, con saldo, ingresos y gastos.
  4. Utilizar los cinco apartados del menú inferior: Inicio, Movimientos, Metas, Estadísticas y Retos.

3. Pantalla Inicio

Presenta el saldo total (ingresos menos gastos), totales acumulados y del mes, acceso rápido a ingresos y gastos, una meta activa y los movimientos recientes. Los importes se muestran en dólares.

4. Registrar un ingreso o un gasto

  1. En Inicio pulsar Ingreso o Gasto, o abrir Movimientos y utilizar el botón +.
  2. Escribir un monto positivo, una descripción y una fecha.
  3. Seleccionar una categoría compatible con el tipo de movimiento.
  4. Presionar Guardar. El sistema recalcula saldo y estadísticas.

Ejemplo de prueba: ingreso de $20.00 y gasto de $5.00 → saldo esperado $15.00.

Editar o eliminar

Entrar a Movimientos, pulsar el registro; editar sus datos o eliminarlo confirmando la operación. Usar filtros por tipo y categoría cuando sea necesario.

5. Categorías

En Movimientos pulsar Categorías. Permite añadir nuevas categorías de ingreso o gasto. Si se elimina una categoría que ya posee movimientos, la aplicación solicita trasladarlos a otra categoría del mismo tipo antes de continuar.

6. Metas de ahorro

  1. Seleccionar Metas y pulsar +.
  2. Indicar el nombre y el monto objetivo, mayor que cero.
  3. Guardar y pulsar Abonar sobre una meta para incrementar su monto acumulado.
  4. Observar el porcentaje de avance y la cantidad restante.
  5. Usar Editar para modificar o eliminar una meta.
En esta implementación los abonos aumentan monto_actual de la meta, pero no crean movimientos financieros ni descuentan dinero del saldo. No representan una transferencia bancaria.

7. Estadísticas

En Estadísticas se elige el mes; la pantalla muestra ingresos, gastos y saldo del período, un gráfico de barras de seis meses y una gráfica circular de los gastos distribuidos por categoría.

8. Retos, rachas y logros

En Retos se crea un objetivo con descripción, condición y monto opcional. El botón Lo cumplí hoy registra como máximo una marca diaria por reto. Se pueden marcar retos cumplidos, fallidos o reactivarlos. El sistema dispone de seis logros predefinidos, entre ellos Primer registro, Primera meta, Meta cumplida y Ahorrador.

9. Ajustes, copia de seguridad y recuperación

  1. Pulsar el icono de engranaje.
  2. Para conservar la información, pulsar Exportar respaldo; se genera un archivo JSON descargable.
  3. Para recuperar una copia, pulsar Importar respaldo y elegir un JSON compatible. Esta acción reemplaza los datos actuales previa confirmación.
  4. Borrar todos mis datos restablece la aplicación. Hacer copia previamente.

Si se borra el almacenamiento del navegador, se pueden perder los movimientos y metas. Se recomienda exportar un respaldo periódicamente.

10. Problemas frecuentes

SituaciónQué hacer
El monto no se guardaComprobar que sea mayor que cero y tenga hasta dos decimales.
No se muestra una categoríaVerificar si es categoría de ingreso o de gasto; crear otra si hace falta.
Datos desaparecidosRevisar si se abrió el mismo navegador/perfil; importar respaldo JSON si existe.
El navegador restringe almacenamiento localProbar en Chrome o Edge con almacenamiento permitido y comprobar que persiste al reabrir.
